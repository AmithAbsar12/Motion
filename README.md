# Motion Concepts Assessment

Four interactive studies recreated from the supplied design frames and reference videos. The project uses JavaScript, React, GSAP/ScrollTrigger, React Three Fiber, Drei and Vite.

## Run locally

```bash
npm install
npm run dev
```

Build the production bundle with `npm run build`.

## Routes

- `/concept-1` — scroll-controlled banner reveal
- `/concept-2` — parallax card-flip sequence
- `/concept-3` — interactive WebGL fantasy map
- `/concept-4` — CTA and underwater footer

The root route provides a visual concept selector. Each experience includes a reduced-motion fallback, responsive layout and keyboard-accessible native controls.

## Content notes

The service copy, external navigation destinations and contact details are demonstrative because final client URLs and approved copy were not included in the source package. The underwater artwork is a flattened source image, so depth, light and particle motion are layered around the composition rather than applied to isolated creatures.
